Code 128 Label Generator for ASN in Paperless-ngx

Fork adapted for Avery L4731 pair layout: one label holds a Code 128 barcode with payload PREFIX + number, the next label holds large digits only. That yields 94 pairs + 1 empty trailing label per A4 sheet (7 × 27 = 189 cells).

Validated @300 DPI (no upscale) with zxing in the dok-paperless path: 94 / 94 page-wide reads. Short payloads (default: no leading zeros, e.g. ASN1) scan more reliably than padded QR codes on this label size.

Enable Paperless ASN barcodes (PAPERLESS_CONSUMER_ENABLE_ASN_BARCODE + PAPERLESS_CONSUMER_ENABLE_BARCODES) and keep the prefix in sync with PAPERLESS_CONSUMER_ASN_BARCODE_PREFIX.

Print 1:1 on Chrome/Chromium (CSS @page).

One sheet covers 94 ASNs. Next batch should start at 95.

Must match PAPERLESS_CONSUMER_ASN_BARCODE_PREFIX (default ASN).

Prefer 0 for short payloads (ASN1… — longer padded strings need narrower modules and scan worse @300 DPI.

Useful for debug / print calibration. Blue = barcode cell, red = text cell, gray = empty.

Based on tmaier/asn-qr-code-label-generator (AGPL-3.0). Adapted for Code 128 pair layout for local Paperless-ngx use.
